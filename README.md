Versão **Ventura** do clássico *build-your-own-x* — aprenda construindo: guia
curado de projetos para recriar ferramentas famosas do zero, com uma skill de
replay determinístico para executar cada construção em etapas.

> **Curadoria original** — este repositório organiza projetos de reconstrução
> de forma própria; a lista completa de tutoriais vive no projeto original
> (build-your-own-x).

## O que é

A melhor forma de aprender uma tecnologia é reconstruí-la. Este guia curado
lista categorias de projetos — do mais simples ao mais avançado — e a skill
`SKILL.md` transforma cada construção em processo determinístico.

## Categorias de projetos

| Categoria | Projeto típico | O que ensina |
|---|---|---|
| **Servidor web** | HTTP server do zero | protocolos, sockets, concorrência |
| **Banco de dados** | banco em memória / SQL | armazenamento, indexação, queries |
| **Interpretador / Compilador** | linguagem simples | parsing, AST, execução |
| **Git** | controle de versão básico | blobs, commits, branches |
| **Shell** | terminal interativo | processos, pipes, ambiente |
| **Bot / API** | bot de chat / REST client | I/O, rede, automação |
| **Jogo** | jogo de terminal / 2D | loop de jogo, estado, input |
| **Framework** | framework web / CLI | abstração, extensibilidade |

## Princípios do método

1. **Comece pequeno** — versão mínima funcionando primeiro.
2. **Cada etapa compila** — sempre com algo executável nas mãos.
3. **Compare com o real** — entenda onde sua versão difere do original.
4. **Não copie** — escreva com suas próprias decisões.

## Como usar (com a skill)

```text
1. Modo EXPLORE  — escolha o projeto e estude o que ele faz (uma vez)
2. Modo COMPILE  — registre o plano em projeto.md (etapas, entregas, testes)
3. Modo REPLAY   — implemente a próxima etapa, sem replanejar tudo
4. Modo REGENERATE — requisito novo/erro de arquitetura → regenere o plano
```
